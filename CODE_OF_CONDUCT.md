# Code of Conduct

Agent-Session-Relay welcomes contributors of every background, identity, and experience level.

Be respectful. Discuss code and ideas without attacking people. Give actionable feedback, credit
others' work, and accept corrections. Help newcomers understand the project and make room for
different communication styles and languages.

Harassment, discriminatory remarks, threats, sexualized conduct, deliberate disruption, and sharing
someone's private information without permission are unacceptable in project spaces and when
representing this community elsewhere.

Maintainers may edit or remove inappropriate contributions, restrict participation, or ban repeat
or serious offenders. Decisions should be proportionate and explained to those affected when possible.
Maintainers are accountable to the same standards.

Report conduct concerns privately to a repository maintainer through the contact information on their
GitHub profile. Do not publish private details in an issue. Reports will be handled discreetly, with
information shared only as needed to investigate and respond. Retaliation for a good-faith report is
not acceptable.
