# Agent-Session-Relay v0.4.0

Agents can inspect project history outside the current Relay session with
`relay agent git <subcommand> <args...>`. For example:

```bash
relay agent git log --graph --oneline main
relay agent git show abc123:path/to/file
relay agent git diff main~2 main -- src/
relay agent git merge-base --is-ancestor abc123 main
```

## Changes

- The new command allows explicitly supported read-only Git command/option combinations.
  Write operations, unknown forms, aliases, and Git global options are rejected. Mixed read/write
  commands expose query forms such as `branch --list`, `config --get`, and `worktree list`.
- Direct Git calls remain blocked during active sessions. The new entry point works in normal
  and btw turns and validates queries inside the command, independently of the Kiro hook.
- Query arguments, current directory, standard streams, and Git exit codes are preserved,
  including binary output and `diff --exit-code`. Query execution suppresses common side effects
  such as optional index refresh, external diff/textconv, and lazy fetches. Query-like forms that
  can write, including `describe --dirty` and `diff --output=file`, are rejected.
- Queries may reference Relay-managed refs, branches, and commits. Compact injected guidance
  prefers `relay agent diff` for current-session changes and discourages interpreting internal
  bookkeeping as ordinary project history; target names are not used for access restrictions.
- CLI help, agent status, guard guidance, and English/Chinese documentation describe the new
  interface. See [supported queries and execution behavior](../agent-git.md), including the
  existing trust boundary for repository configuration, ordinary filters, and executable code.

## Upgrading from v0.3.0

The session metadata remains schema 2; existing v0.3.0 sessions need no migration. Kiro hook
configuration uses the same CLI entry points and does not need to be reinstalled.

Upgrade your installation, for example with `pipx upgrade agent-session-relay`, and check that
`relay --version` reports `0.4.0`. For standalone installations, replace `relay.pyz` with the new
archive. Subsequent prompt hooks inject the updated query guidance.

Users upgrading from v0.2.x must first follow the session cleanup instructions in the
[v0.3.0 release notes](v0.3.0.md).
