# Agent-Session-Relay v0.8.1

Fixes `relay finish` reporting "Pending changes remain" immediately after `git add .` when
earlier session snapshots contain files that have since been added to `.gitignore`.

## Finish checks follow the current index and ignore rules

- Previously captured files that are now ignored and absent from the index no longer block
  finish. This includes staged removal of a now-ignored file with `git rm --cached`.
- `relay status --json` uses the same check for `unstaged_changes`, keeping its diagnostic
  consistent with finish in both single-repository and multi-repository sessions.
- Unstaged tracked edits and non-ignored untracked files still block finish. Files force-added
  despite ignore rules remain subject to review, including edits made after staging.
- Ignored files remain on disk after finish, including in workspace members with no net changes
  that return to their origin without creating a result commit.
- Full snapshots still preserve previously captured files for BTW restoration, suspend/resume,
  abort, and interrupted-operation recovery. The result commit contains exactly the staged tree.

Regression tests cover ignore changes across turns, staged removals, force-added ignored files,
multi-repository finish, and preservation of ignored files in unchanged members.

## Compatibility and upgrading

The package version is `0.8.1` and the Git tag is `v0.8.1`. Per-worktree metadata remains schema 2,
and workspace metadata remains schema 1. Existing sessions need no migration, and hooks do not
need to be reinstalled.

Upgrade with `pipx upgrade agent-session-relay` and verify that `relay --version` reports `0.8.1`.
For standalone installations, replace `relay.pyz` with the new archive. Users upgrading from
v0.2.x must first follow the [v0.3.0 cleanup instructions](v0.3.0.md#upgrading-from-v02x).

Maintainers can follow the [release instructions](../../CONTRIBUTING.md#releases). The tag workflow
creates a draft GitHub release; PyPI upload and publication of the draft remain explicit steps.
