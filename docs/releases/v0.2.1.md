# Agent-Session-Relay v0.2.1

`relay abort` now asks for one confirmation: type `abort` to preserve the current
workspace in a recovery branch and end the session. The warning includes the
recovery branch name and explains that session history and staging distinctions
will be removed. EOF or any other response cancels without cleanup.

CLI help, English and Chinese documentation, and workflow tests have been updated
to match the single-confirmation flow.
